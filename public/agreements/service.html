产品服务协议

本协议规定了平台向用户提供产品和服务的具体条款。

一、服务范围

本平台提供以下服务：
1. GPU云实例：按需创建和管理GPU计算实例；
2. 镜像服务：提供预置和自定义镜像管理；
3. 存储服务：提供数据存储和管理功能；
4. 应用市场：提供预置AI应用和模型部署。

二、计费规则

1. 按量计费：根据实际运行时长和资源规格计费，按秒级线性计算，每15分钟结算一次；实例仅在运行状态下计费，停机、过期挂起及节点离线挂起期间不计费；
2. 套餐计费：用户可购买月卡等套餐享受优惠；
3. 余额充值：支持微信支付等方式充值，充值后不可提现；
4. 欠费处理：允许账户在欠费状态下继续运行，欠费累计达到10元时运行中的实例将被强制停止；强制停止后10日内充值恢复余额可手动重新开机，超过10日未充值的实例将被自动释放，实例内数据不再保留。

三、实例停机与资源回收

1. 停机不预留算力：实例停机后（包括用户主动关机、欠费强制停机、到期挂起及节点离线挂起）停止计费，同时其占用的 GPU、CPU、内存等算力资源将被释放回公共资源池，并可能被其他用户占用；按量计费与套餐（包年包月）实例均适用本条，停机期间均不为用户预留或锁定特定资源；
2. 数据保留与节点绑定：实例的数据盘存储于其所在计算节点本地，停机期间数据保留，但实例仅能在原节点重新开机，不支持在保留数据的前提下迁移至其他节点；
3. 开机不作担保：重新开机时，若原节点的 GPU 或 CPU、内存资源已被其他实例占用致使可用量不足，开机将失败，需等待资源释放后重试。平台不对停机后能否立即成功开机作出承诺，因资源被占用导致的开机失败不计入 SLA 不可用时长；
4. 使用建议：短时间内仍需使用的实例建议保持开机；长期不使用的实例建议先将容器内重要数据备份至外部存储后再关机或释放。

四、退款政策

1. 账户余额不支持退款提现；
2. 因平台原因导致的服务不可用，将按实际影响时长进行补偿；
3. 套餐类产品一经购买不支持退款。

五、服务保障（SLA）

1. 平台承诺月度服务可用性不低于99.5%；
2. 计划内维护将提前24小时通知用户；
3. 非计划停机将在发现后第一时间通知用户并尽快恢复；
4. 因SLA未达标造成的损失，将根据影响程度给予账户余额补偿。

六、数据安全

1. 用户数据存储在安全的基础设施上；
2. 平台不主动访问用户实例内的数据；
3. 实例释放后，相关数据将在7天内彻底删除；
4. 建议用户定期备份重要数据。

七、违约责任

1. 用户违反使用规范，平台有权暂停或终止服务；
2. 因用户违规导致平台损失的，用户应承担赔偿责任；
3. 因平台原因导致用户损失的，赔偿上限为用户最近12个月支付的费用总额。
